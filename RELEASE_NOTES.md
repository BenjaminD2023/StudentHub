# Student Hub v0.1.0

The first public Student Hub release connects school planning, writing, files, and focus tools across macOS, iPhone, and iPad.

## Included

- Quick Command on every platform, with `Option-Space` global access on macOS
- Natural English and Chinese date recognition
- Pomodoro, custom countdown, and count-up timer commands
- Colored calendar scheduling linked with tasks
- Projects, subtasks, deadlines, meetings, reminders, and exports
- Obsidian-style live Markdown editing, folders, tabs/windows, and Markdown tools
- User-managed Spaces with direct delete options
- Files, PDF preview, and annotation support
- Dated/undated journal entries and meeting summaries
- Native responsive layouts with light and dark mode

## Verification

- 18 automated tests pass on macOS
- Debug builds pass for macOS, iPhone simulator, and iPad simulator
- iPhone UI smoke-tested for Quick Command, timer routing, Spaces, Notes, and active-line Markdown rendering

## macOS installation note

The attached macOS ZIP is ad-hoc signed and is not notarized by Apple. Control-click the app and choose **Open** if Gatekeeper asks for confirmation. The source archive is available on this release for reproducible local builds.
